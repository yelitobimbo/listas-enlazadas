# Listas Enlazadas en Java

Tarea de **Estructuras de Datos**: implementación de listas enlazadas simples en Java, hechas desde cero con las clases `Nodo` y `ListaSimple` (sin usar `LinkedList` ni `ArrayList`).

**Alumna:** Yaneli Sánchez Cárdenas
**Grupo:** GTID244
**Universidad:** Universidad Tecnológica del Norte de Guanajuato (UTNG)

## Ejercicios

| Carpeta | Ejercicio | Problema de omegaUp | Qué hace |
|---|---|---|---|
| `ej2_cuenta_letras` | Ejercicio 2 - Cuenta letras | cuenta_letras_al_vector | Cuenta cuántas veces aparece cada letra del alfabeto en una palabra |
| `ej4_insercion_lista` | Ejercicio 4 - Inserción | Inserción en Lista Enlazada | Mete un nodo con -1 antes de cada número impar |
| `ej6_busqueda_lista` | Ejercicio 6 - Búsqueda | Cajas de dulces | Busca la suma más grande de K nodos seguidos |
| `ej8_invertir_lista` | Ejercicio 8 - Inversión | Derdenio y sus Estructuras de Datos | Junta dos listas ordenadas y las deja de mayor a menor |

Los 4 ejercicios fueron aceptados en omegaUp con 100%.

## Estructura de cada carpeta

- `Nodo.java`: guarda un dato y el puntero `siguiente`.
- `ListaSimple.java`: guarda la `cabeza` y los métodos de cada ejercicio.
- `Main.java`: lee los datos, usa la lista e imprime el resultado.

## Cómo correrlo

Dentro de la carpeta de un ejercicio:

```
javac *.java
java Main
```

Después se escriben los datos de entrada del problema.
